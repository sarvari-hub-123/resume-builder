# 📄 Resume Builder

A modern and responsive Resume Builder application built with **React.js**, **Redux Toolkit**, **Material UI**, and **React Hook Form**. Users can easily create professional resumes, choose from multiple templates, preview them in real-time, and download them as PDF files.

## 🌐 Live Demo

🔗 https://resume-builder-ruby-sigma.vercel.app

## 📂 GitHub Repository

🔗 https://github.com/VadderaMalleswari/resume-builder

---

# ✨ Features

- 👤 Personal Information Form
- 🎓 Multiple Education Entries
- 💼 Multiple Work Experience Entries
- 🚀 Projects Section
- 🏆 Certifications Section
- 🛠️ Dynamic Skills Section
- 🖼️ Profile Photo Upload
- 📑 Three Resume Templates
  - Professional
  - Modern
  - Simple
- 👀 Live Resume Preview
- 📥 Download Resume as PDF
- 📱 Responsive Design

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/VadderaMalleswari/resume-builder.git
```

Go to the project folder

```bash
cd resume-builder
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```

Build for production

```bash
npm run build
```
