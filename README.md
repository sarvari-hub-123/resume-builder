# Resume Builder 🚀

A modern Resume Builder web application that allows users to create professional resumes, choose templates, preview them instantly, and download them as PDF.

## Features

- 📝 Multi-step resume creation
- 👤 Personal information section
- 💼 Work experience section
- 🎓 Education details
- 🛠 Skills section
- 🎨 Multiple resume templates
- 👀 Live resume preview
- 📄 PDF download
- 📱 Responsive design

## Technologies Used

### Frontend
- React.js
- JavaScript (ES6)
- Material UI
- Redux Toolkit
- React Router
- React Hook Form

### Libraries
- jsPDF
- html2canvas
